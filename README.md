# Заметки проекта

Здесь будут находиться пояснения по работе со справочником горячих клавиш.

## Категории

- Файлы и навигация
- Редактирование текста
- Поиск и замена
- Работа с терминалом

## Как пользоваться справочником

1. Определите нужную категорию действий.
2. Найдите требуемое действие в таблице.
3. Проверьте указанное сочетание клавиш в редакторе кода.

 ## Основные сочетания клавиш

| Действие | Сочетание клавиш | Категория |
| --- | --- | --- |
| Открыть файл | Ctrl + P | Файлы и навигация |
| Закомментировать строку | Ctrl + / | Редактирование текста |
| Открыть встроенный терминал | Ctrl + ` | Работа с терминалом |


## Пример настройки собственного сочетания

```json
{
  "key": "ctrl+alt+s",
  "command": "workbench.action.files.saveAll"
}
```
