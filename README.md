# План тренировок

# Цель проекта

Составить план для тренировки по которому можно будет набрать мышечную массу за определённое количество времени.

## Список упражнений

1. Бегит
2. Пресс качат
3. Атжумания
4. Приседания



 ## Табица подходов

| Название упражнения | Количество подходов | Количество повторений |
| --- | --- | --- |
| Бег | 100 | 2 |
| Упражнение на пресс | 60 | 2 |
| Приседания | 60 | 3 |
|Отжимания   |  30        |       3           |
